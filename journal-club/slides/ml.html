Next is machine learning, the part I'm most interested in for the rotation. Dictionary matching compares every voxel with every entry, so the cost grows with the dictionary. A neural network learns the mapping from signal to parameters once, and after that it's a single pass per voxel. This figure is also from Hongli Fan. The network rows, labeled ANN, are cleaner than dictionary matching, DM, and the green arrows mark artifacts the network removed. Total processing went from 3 hours 12 minutes to 3.6 seconds. DeepMARS reported under half a millisecond per voxel, versus more than 4 seconds. For MRvF, Lin and colleagues trained a network on simulated GESFIDE dictionaries and got better accuracy than matching for CBV, radius and SO2. The caveat is that most of these networks learn from simulations. This one is an exception, trained on experimental data. If a voxel looks unlike anything in training, a network can still return a plausible number, with no warning.
