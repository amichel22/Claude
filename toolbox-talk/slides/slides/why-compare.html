You asked why it makes sense to compare these models at all. Here's how I think about it. In a human scan we can't measure the true vessel radius voxel by voxel. In a simulation we set it, so we know it exactly. So Berman's group made test signals with the 3D reference recipe, where the radius is known, and then asked each of the other recipes to recover it, each using a dictionary built with that recipe. Same physiology, same settings; only the recipe changes. So if the reported radius moves, it's the recipe that moved it. Why should we care? Because a dictionary carries the physics of whatever simulated it, and matching always finds some best entry, even when that physics is off. Nothing in the matching step tells you it's wrong. So if two reasonable recipes report different radii for the same signal, the recipe itself is a source of error in every map we make with it. Why that reference? Random 3D cylinders have exact formulas for the field, no grid artefacts, the most direct diffusion model, decades of use, and most of the shortcuts were derived from them. One honest caveat: it's still a model, straight, randomly oriented cylinders. Berman calls it ground truth only for cylinder simulations. So this measures agreement with the best-understood recipe, not the truth in real tissue. But it tells us to check which recipe built our own dictionary.
