You asked why it makes sense to compare these models at all. Here's how I think about it. In a human scan we can't measure the true vessel radius voxel by voxel. In a simulation we set it, so we know it exactly. So Berman's group made test signals with the 3D reference recipe, where the radius is known, and then asked each of the other recipes to recover it, each using a dictionary built with that recipe. Same physiology and the same sequence; only the recipe changes. So if the reported radius moves, it's the recipe that moved it. Why should we care? Because a dictionary carries the physics of whatever simulated it, and matching always finds some best entry, even when that physics is off. In Berman's 3B0 panel, several of the wrong picks sit on pale, high-scoring cells, so a good fit didn't mean a right radius. So if two reasonable recipes report different radii for the same signal, the recipe itself is a source of error in every map we make with it. Why that reference? Random 3D cylinders have an exact formula for the field and no grid artefacts. Berman says Monte Carlo diffusion may be considered the most accurate way to model diffusion. The field has a lot of experience with this model, and many of the later shortcuts were derived from it. One honest caveat: it's still a model, straight, randomly oriented cylinders. Berman calls it ground truth only for cylinder simulations. So this measures agreement with the best-understood recipe, not the truth in real tissue. But it tells us to check which recipe built our own dictionary.
