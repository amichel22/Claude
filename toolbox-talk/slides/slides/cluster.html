Everything so far ran on a laptop. A real dictionary is bigger, and that's where the cluster comes in. One 3D simulation takes about 35 seconds on one core at 3 percent blood volume; more vessels take longer. A first real dictionary, say 25 radii, 15 blood volumes and 3 random voxels each, is about 1,100 runs. That's 10 to 12 hours on one core if every entry cost the same, and more once the high blood volumes are in. But each run is independent, so as 30 jobs side by side on the cluster it takes about an hour. Two things make this manageable. Oxygenation is free, because one run can be rescaled to any SO2. And each run uses one core, so it maps onto array jobs the same way the MrVox jobs are already split.
